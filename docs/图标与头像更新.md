# 图标与头像更新

公开角色目录、角色详情页和后台角色目录使用真实角色头像；配队使用角色头像并保留姓名和职责。武器推荐、武器对比、圣遗物搭配和顶部快速配装使用真实装备图标并保留名称、套装件数和说明。后台攻略预览复用同一套显示组件。

图片保存在 `public/game-icons/`，名称索引保存在 `src/data/game-icons.json`。此次资源包含 124 个角色名称条目、255 个武器条目、63 个圣遗物套装条目，共 441 张 PNG（部分条目共用图标）。这份索引用来匹配图片，不会自动增加网站的角色目录或攻略。

现有攻略的文字格式无需改变，例如：

```text
铁蜂刺｜锻造获取；精通方向。
翠绿之影 · 4 件套｜风元素辅助方向。
翠绿之影2件套 + 昔日宗室之仪2件套｜混搭说明。
枫原万叶｜辅助
```

支持常见简称，例如万叶、雷神、草神、风套、绝缘套和薙草。混搭装备或同位置的候选角色会显示多个对应图标。尚未收录的名称保留文字并显示中性占位图，不会强行匹配其他角色或装备。

名称与游戏图片文件名参考 [genshin-db](https://github.com/theBowja/genshin-db)；PNG 从 [Enka.Network 的游戏 UI 资源](https://enka.network/ui/UI_RelicIcon_15002_4.png)保存到项目中。游戏图像归原权利人所有。网页加载这些图片时无需访问上述服务。

后续需要扩充图标库时，可以手动执行 `node scripts/sync-game-icons.mjs`。脚本只更新本地图标和名称索引，不会上线或部署网站。
