# 图片攻略改版 · 2026-10-23

## 使用结果

前台：选择角色 → 完整攻略图片 → 作者评语。去掉大幅角色横幅、玩法方案切换、快速配装、侧边索引、武器对比和材料勾选。多份攻略直接连续展示，推荐攻略优先，其余按更新时间排列；旧分享链接指定的攻略会放到首位。

后台：选择角色 → 上传图片 → 填写作者及评语 → 发布。图片上传后直接可用，无解析队列、模块整理或额外确认页。标题按角色自动填入，版本和来源选填，展示效果可在页内展开。支持多图上传、排序、替换、移除和保存草稿。

长图按原比例显示，点击可在当前页面放大，支持原尺寸与 Esc 关闭。作者评语放在图片下方。图片作者与整理发布管理员分别显示；讨论默认收起，原有评分和点赞数据保留。

首页卡片、空白提示、工作台、登录注册说明、旅行指南、README、管理员手册和技术说明已同步修改。

## 数据兼容

不批量改写已有攻略。旧图片模块在阅读时直接显示，打开编辑器后自动适配新的图片列表。旧文字攻略保留正文，仍可编辑和发布。新格式以版本 JSONB 中的 format、imageIds、imageAuthor、authorComment 记录，不需要新增数据库表。

保留原账号权限、私有草稿、版本记录、修订冲突保护、下架和文件访问控制。新图发布前私有；移除图片后重新发布、下架或隐藏角色时，对应公开访问会撤销。

每张图片最多 3 MB，一份攻略最多 20 张。原始图片不做有损改写，后续图片惰性加载。大于上传限制的图片需另存为体积合适的清晰图片。
