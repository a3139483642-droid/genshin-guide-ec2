# 五星角色目录扩充

更新日期：2026-10-23。角色资料核对至 7.1 版本。

角色图鉴由 8 个条目扩充为 71 个条目，新增 63 个；空、荧分别收录，元素显示为“元素可切换”。不收录千星奇域的两种奇偶形象。原有深蓝、米白与金色配色、角色卡片、头像、元素标记和详情页排版沿用现有样式。

## 内容与行为

- 每位角色包含中文名称、称号、元素、武器、别名、英文名和定位标签，头像使用项目已有的本地游戏素材。
- 原有 8 位角色维持开头顺序，后续角色按初登场版本排序，每页 24 位，共 3 页；编号连续为 01–71。
- 姓名、别名、英文名、武器搜索和元素筛选继续可用。旅行者在七种元素筛选下均可找到。
- 已有数据库会自动补入缺失角色；同名自建角色不会重复插入。原有角色字段、排序、可见性、推荐方案与已发布攻略不覆盖。
- 新角色继续显示“攻略待补充”，可在后台选择并发布攻略。

## 维护

角色快照保存在 `server/characters.mjs`。手动刷新命令为 `node scripts/sync-characters.mjs`。该脚本从资料源读取中文与英文名称，并检查本地头像是否齐全；新增角色需要先确认标签再刷新。网站运行时无需连接外部资料服务。
