# 管理员操作手册

## 首次使用

访问 `/setup` 创建唯一站长。本站没有默认管理员密码。线上需填写部署环境的 `SETUP_KEY`；本地空站点可直接初始化。普通用户可注册并参与讨论。

站长可在“账号与权限”创建发布管理员。停用账号或更改角色后，旧会话立即撤销；唯一站长不能删除、降级或停用。

## 站长专属记忆相簿

站长登录后，在后台导航点击“记忆相簿”，地址为 `/admin/manage/memories`。发布管理员和普通用户没有入口，直接访问页面或图片接口也无法查看。

1. 点击“选择照片”或将图片拖入上传区域，可以一次选择多张 PNG、JPEG、WebP 图片，每张最多 3 MB。上传保留原图，上传进度与失败原因会显示在页面中。
2. 照片按上传时间倒序显示，每页 24 张。可按标题、备注和原文件名搜索。
3. 点击照片放大查看，可修改标题和备注、下载原图，或切换同页的上一张/下一张。输入备注后点击“保存备注”。
4. 在照片查看窗口点击“删除照片”并确认，会删除该照片及当前存储的原图。历史站点备份仍保留备份时的内容。

相簿使用独立的 `memory_photos` 表与私有文件，不进入公开攻略素材库。每次读取原图都重新检查站长会话，退出登录后原图地址立即失效；相簿记录与图片随既有站点备份和恢复脚本一起处理。更新后的程序首次启动会自动创建相簿表，旧备份可继续恢复。

## 发布图片攻略

1. 工作台点击“发布攻略”，或左侧“发布图片攻略”。
2. 选择所属角色，标题自动填写为“角色名攻略”，可以修改。
3. 选择或拖入 PNG、JPEG、WebP 图片，可一次选择多张；每张最多 3 MB，一份攻略最多 20 张。原图保持不变，直接上传，不等待文字识别或解析。
4. 通过“上移 / 下移”调整阅读顺序，也可替换或移除图片。
5. 图片作者和作者评语均选填。原作者署名与上传管理员分别记录；填写作者评语时请说明玩法、心得或必要补充。
6. “版本与来源”默认收起，需要时填写。版本空白会标明未注明。
7. 如需检查效果，展开页内“查看展示效果”。点图放大，Esc 或“关闭”回到原位。
8. 直接点击“发布攻略”，系统会先保存再发布；也可以保存草稿稍后继续。无须额外切换预览页面或勾选发布确认框。

上传中不可保存或发布；部分上传失败时，已成功上传的图片仍保留在当前页面。离开未保存的页面可能丢失当前编辑；关闭或刷新浏览器时会提示未保存修改。

## 阅读方式

点角色卡片直接看完整长图和作者评语。推荐攻略优先，其余按更新时间排列；分享链接可将指定攻略放在首位。手机上图片按原比例缩放，向下滑动即可阅读。点击图片可原位放大或切换原尺寸，无须打开新窗口。

讨论入口在攻略底部，默认收起。原有评分、点赞和历史评论数据保留，评分和点赞不再占用阅读页。

## 更新与下架

- 发布管理员可管理自己的未发布草稿，首次发布后由站长维护更新；权限规则沿用原设置。
- 站长可编辑全部攻略。保存草稿不会影响公开版本；“更新发布”才切换内容。作者、评语、图片顺序和来源均随版本保存。
- 同一草稿被其他窗口修改时，旧修订会报冲突，避免覆盖。请保留手头修改后重新载入。
- 下架后公开入口返回 404。没有其他公开攻略引用的图片变回私有；旧版本和文件仍保留。
- 在“角色目录”可设置优先展示的攻略；未设置时按更新时间展示。

## 旧资料兼容

旧图片攻略无需重新上传，会直接显示原有图片。旧文字攻略用普通正文连续展示；编辑时可以在“原有文字内容”中修改，模块类型与来源记录在数据中保留。新发布入口不再提供拆分、合并、武器对比或材料勾选操作。

工作台底部保留折叠的“历史文档导入记录”。已完成任务可打开继续发布；尚在处理的任务请稍后重新载入。历史 TXT、Markdown、DOCX、PDF 的解析服务和原件仍保留，原始文档默认私有。

## 评论与文件权限

站长可在“评论与举报”隐藏、恢复评论及处理举报。普通用户只能删除自己的评论。

未发布图片为私有素材，发布后只有当前公开攻略引用的展示图片可公开访问。上传文件校验实际格式；文本按普通文字显示，不执行来源中的 HTML 或脚本。站点备份包含数据库、图片和原始文件，恢复操作仍通过管理脚本执行。
