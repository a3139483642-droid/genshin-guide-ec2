# 站长专属记忆相簿

入口：站长后台 → 记忆相簿（`/admin/manage/memories`）。

## 功能

- 多选或拖入图片，逐张上传并报告进度与失败原因；PNG/JPEG/WebP，每张最大 3 MB，保留原件。
- 响应式照片网格、原图查看、同页上一张/下一张、原图下载、照片标题与备注编辑、确认删除。
- 按标题/备注/文件名搜索，每页 24 张，按收藏时间倒序展示。
- 唯一 `owner` 角色可访问。后台入口与页面有权限保护；全部相簿 API 在读取数据、解析上传之前校验站长身份，原图与下载同样检查登录态并禁止缓存。
- 独立相簿表及 `memory-<id>` 私有存储键，与公开攻略素材隔离；无法通过攻略发布接口将相簿图片公开。
- 自动建表，纳入现有数据库和文件备份；兼容尚不包含相簿表的旧备份。

## 验证

- `npm run build`：生产构建通过。
- `npm test`：43 项测试通过，其中新增相簿测试覆盖三类账号与匿名访问、CSRF、中文文件名、原件字节、下载权限、格式与大小限制、备注、检索、分页、Netlify 原生函数二进制上传与读取、备份恢复、删除与退出后的访问撤销。
- 浏览器使用独立临时数据库验证：站长登录、多图上传、查看原图、编辑保存、备注搜索、同页图片切换与原图下载；下载字节与原文件一致。1280 像素桌面与 360 像素窄屏均无横向溢出；发布管理员无入口且无法直接打开相簿。未观察到浏览器控制台错误。
- 截图中的照片与账号是独立测试环境的样本，图片取自项目已有公开素材；未向实际 `.data` 写入测试照片或账号。
