# 提瓦特旅行手册

按 `docs/PRD.md` 与浅色冒险手册样稿实现的原神角色攻略网站。前台、管理后台、API、关系数据库和私有文件存储均为实际实现。部署目标为 **Netlify**；本次按用户要求只交付网站和部署包，不代为上线。

## 先运行网站

日常本地测试可直接双击上一级目录的 `双击启动网站.bat`。浏览器会在服务就绪后自动打开；首次使用进入站长初始化页。保持启动窗口打开，测试结束按 Ctrl+C 停止。账号和照片保存在本项目 `.data`，下次启动继续使用；重复双击会打开已经运行的网站。

需要 Node.js 22.12+（已在 Node.js 24 验证）。在本目录打开终端：

```powershell
npm ci
npm run dev
```

打开 `http://127.0.0.1:4173`，点击“初始化站点”，创建你自己的唯一站长账号。**没有内置默认管理员密码。** 可选择添加一份明确标注的功能示例攻略，也可从空白内容开始。

本地使用 PGlite（PostgreSQL 引擎），数据写入 `.data/postgres`，原件与图片写入 `.data/files`。关闭并重新启动后数据仍保留。不要同时启动两个进程访问同一个数据目录。

```powershell
npm test        # 权限、导入、互动、版本、恢复验收
npm run build  # 生成 dist
npm start      # 运行本地生产构建
npm run package # 生成 deliverables/teyvat-netlify-source.zip
```

交付前还通过了 Netlify 离线构建与实际函数 ZIP 运行检查。重新检查函数包时，先运行 `npx netlify-cli build --offline`，再运行 `node scripts/verify-netlify.mjs`；这两步不部署站点。

也可以在 PowerShell 中运行 `./启动网站.ps1`。本地服务只监听当前电脑的 127.0.0.1；正式发布请使用 Netlify。

## 图片攻略改版（2026-10-23）

前台和后台均已精简为图片阅读与作者评语。旧攻略不需批量迁移；只有编辑并发布时才生成新版本。具体修改、界面截图与验收记录见 [图片攻略改版](docs/图片攻略改版-20261023/说明.md)。

## 已实现

- 站长专属记忆相簿：后台“记忆相簿”入口，多图上传、原图查看与下载、标题与备注、搜索分页和删除；页面及图片接口均只允许站长，图片与攻略素材独立存储，并随站点备份恢复。支持 PNG/JPEG/WebP，每张最多 3 MB。
- 公开角色图鉴，名称/别名/武器检索、元素筛选、已有攻略筛选和分页；无攻略角色保留入口。
- 角色目录核对于 2026-10-23（7.1 版本）：收录全部 51 位四星和 71 位五星，共 122 个角色入口，空与荧分别收录，不包含奇偶人。四星沿用原有卡片、元素配色与详情页，头像全部本地存储；已有数据库会自动补入缺失角色，保留管理员修改和已有攻略。基础资料来自 [genshin-db](https://genshin-db-api.vercel.app/api/v5/characters?query=names&matchCategories=true&verboseCategories=true&resultLanguage=ChineseSimplified)，名单交叉核对 [BWIKI 角色图鉴](https://wiki.biligame.com/ys/角色)。手动刷新目录使用 `node scripts/sync-characters.mjs`。
- 单栏图片攻略：点角色直接阅读完整长图，多份攻略连续展示；作者评语、图片作者与整理发布者分别显示，支持原位放大。
- 账号登录、普通账号注册、站长初始化、多位发布管理员、密码修改、会话撤销。
- 一页发布图片攻略：选择角色、多图上传、排序/替换/移除、填写作者及评语，点击发布自动保存并发布；版本和来源选填，可在页内预览。历史文档导入记录与文字攻略继续兼容。
- 已发布内容的独立草稿、乐观锁、原子发布、版本记录、站长下架/删除、优先展示的攻略。
- 攻略底部的折叠读者讨论、一层回复、作者删除、举报与站长隐藏；历史评分和点赞数据及接口保留。
- 角色目录、账号权限、站点名称和操作日志管理；数据库与原文件备份、空目标恢复脚本。
- Netlify Functions / Background Functions / Scheduled Functions、Netlify Database、Netlify Blobs 适配。

## 明确边界

1. PNG/JPEG/WebP 直接上传，保留原始图片，不经 OCR 或解析队列；每份攻略最多 20 张，每张最多 3 MB。作者与评语均可选填，标题按角色自动生成。历史文档解析接口继续可用。
2. DOCX 提取段落、表格文字和内嵌 PNG/JPEG/WebP。PDF 读取文字层，复杂表格需核对，PDF 内嵌图片需另外上传。
3. 默认单文件 3 MB、PDF 50 页、DOCX 解压总量 25 MB、解析 45 秒超时。UTF-8 文本最多 15 万字符。
4. 角色目录、角色详情和配队使用真实头像，武器与圣遗物使用本地游戏图标；资源索引仅用于匹配图片，不会自动增加角色或攻略。初始化时可选的攻略是**功能示例**，不是已验证的最新游戏攻略。
5. 实际游戏攻略内容由管理员上传。2026-10-23 图片改版已用用户提供的 1080×2692 长图完成桌面和手机界面验收，使用独立测试数据库；不涉及攻略内容正确性或 OCR 识别质量评估。
6. 云端数据库/存储和独立备份接收端需要你在上线时配置。本次未登录 Netlify、未创建收费资源、未执行云端部署。
